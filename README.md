# Insurance Purchase Prediction

A single-neuron Keras model (logistic regression trained with gradient descent) that predicts whether a person buys insurance from their age and affordability.

## Files

- `insurance_prediction.ipynb` – notebook with explanations and outputs
- `code.py` – the same code as a plain script
- `insurance_data.csv` – dataset (`age`, `affordibility`, `bought_insurance`)

## Run

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python code.py
```
